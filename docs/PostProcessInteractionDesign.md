# 后处理功能界面交互梳理

日期：2026-11-03。本文是基于现有工作台和会议需求的**界面设计建议**，供逐项评审，不表示后端或界面已经实现。操作入口、表单字段、对象状态和先后顺序均可调整；具体数据协议与公共接口仍待评审。

本次 UI 实施已增加多文件组织窗口、云图与轨迹的新建入口、空间特征参数表单、导出设置、分析表单与空结果面板，以及示例时间轴播放。下面各条“当前”保留设计时的基线描述；本次实现范围和尚未覆盖的细节以[操作流程说明](PostProcessUserWorkflow.md)和代码为准。文件映射、迹线实际类型、真实曲线/结果、后台处理及导出尚未完成。

## 1. 设计边界与通用规则

后处理独立于工程创建、工况配置和求解运行，直接使用已有 Tecplot、CGNS、VTK 网格/结果；结构与非结构网格使用一致的操作流程。主线为：

```text
导入文件 → 选择数据/区域 → 查看网格与云图 → 创建切面/等值特征/流线
        → 调整样式与查询 → 对比时间或曲线 → 导出
```

界面沿用当前布局：顶部“数据 / 显示 / 特征 / 分析 / 工具”Ribbon；左侧“视图 / 数据 / 对象”；中央 ParaView 风格三维视口；底部时间轴，任务与探针面板按需打开。三个左侧页签可关闭并从“工具 → 面板”恢复。当前示例画布和字段仅为 UI 演示，不代表真实数据。

### 窗口和控件约定

- 简单切换（显隐、视角）直接生效；参数较少的操作使用非阻塞对话框；复杂的时间序列、格式导出和多状态分析采用分步窗口。
- 空字段、无可用数据源时保留入口可发现性；窗口解释缺什么、如何补齐，不提供伪造成功结果。列表中的不可选项可附原因。
- **创建窗口**：先选数据源/区域和字段，再填写功能参数；`创建`提交后对象进入“对象”列表。若只保存了 UI 参数，则标为“草稿”，不显示为已计算。
- **编辑窗口**：双击对象或选择“编辑参数…”，展示原参数。`应用`提交修改并保留窗口，`确定`提交并关闭，`取消`丢弃尚未应用的修改；失败时保留已填写内容。实际提交语义须与异步服务接入时对齐。
- 长耗时任务在“任务与消息”展示等待、执行、完成、失败与可取消状态。只在真实服务返回结果后在画布显示成功或提供实际文件；取消/失败时不冒充成功。
- 表单展示字段名称、分量、点/单元关联和已知单位；未提供的单位/时间/边界类型标为未知，不根据示例或文件名猜测。
- 色标、位置、种子、等值属于**后处理参数**；来流、边界条件、求解步长、求解网格转换和工况生成不在此工作台设置。

## 2. 数据导入：打开已有结果

**入口**：顶部“数据 → 导入结果”或左侧“数据 → 导入”。

**界面链路**：

1. 弹出“导入结果”文件选择窗口，选择一个或多个 Tecplot、CGNS、VTK 文件；也可选择网格和字段分别保存的文件。
2. 若文件组合关系不能自动确定，进入“数据组织”页：选择“独立结果集 / 同一结果的网格与字段 / 时间序列”，列出文件、格式提示、排序；需要时为字段指定对应网格。格式只按实际支持的子集提供选择。
3. 点击“读取”。“任务与消息”显示读取进度；失败时可展开具体文件和原因，允许重试或返回调整。
4. 成功后左侧“数据”出现结果集、结构/非结构类型、Zone/块、可用物理字段及时间信息；选中结果集或 Zone 后，中央出现真实网格。无物理量时只显示网格，不生成云图。

**待确认**：各格式的版本/编码和网格与结果的匹配规则；选择多文件时独立结果和时间序列的默认解释。**当前**：文件选择后只列为待接入，尚未读取。

## 3. 选择、组织与查看数据

### 3.1 数据集和 Zone

- **入口**：左侧“数据”树。展开结果集，选中一个 Zone、块或已有边界；勾选显隐或使用右键菜单。
- **界面变化**：中央显示所选结果；单击只改变选择，双击 Zone 可打开“对象样式…”。状态区显示数据来源、网格类型、区域和时间，不自动打开一张新表单。
- **对象样式窗口**：可见、表面/线框/边线、颜色、不透明度；`应用 / 确定 / 取消`。有物理边界元信息时，可在数据树按已有类型筛选、着色；没有则只按 Zone 名称或编号操作。
- **多结果集**：每个文件或结果集独立显示来源与显隐；关闭一个不清除其他对象。移除数据前提示依赖它的派生对象及影响。

### 3.2 网格、相机和背景

- **入口**：“视图”页的网格/表面/边线开关，以及顶部“显示 → 交互 / 图层 / 视图”。
- **界面变化**：开关作用于明确标注的当前视口或选中对象；旋转、平移、缩放和适配视图直接作用于相机，不改变网格坐标。
- **背景窗口**：“显示 → 视口背景…”，选择预设或自定义单色/渐变颜色，提供`应用 / 取消 / 恢复默认`。初始化参考 ParaView 暖灰；有真实 Viewer 后变化需作用于真实渲染，而非仅改变占位画布。

## 4. 云图：查看标量或矢量模长

**入口**：选中体网格/物面或字段后点“显示 → 新建云图”；也可通过“对象 → 新建 → 云图”（建议补齐）。

**“新建云图”窗口表单**：

| 字段 | 建议控件与说明 |
| --- | --- |
| 数据源 | 下拉选择结果集及 Zone/物面；可从当前选择预填，仍允许修改 |
| 变量 | 从该数据源的可用字段中选；标注标量或矢量模长，以及点/单元关联 |
| 显示位置 | 体网格外表面、已有物面或切片；按数据实际可用性提供 |
| 色标 | 色谱、自动范围/手动最小最大值、色标显隐；缺失值颜色为可选项 |

**确认后**：“对象”列表新增云图对象并保留数据来源；真实渲染完成后中央更新颜色及色标。选择云图对象时仍可编辑色标，基于其**源数据**创建切片等操作；不因生成云图而清空源网格。无字段时提示选择其他数据源。

**当前**：已有云图草稿及字段/色谱表单；数值范围、真实渲染及对象结果仍待接入。

## 5. 切片与多截面

**入口**：“特征 → 添加切面”，或“对象 → 新建 → 添加切面”。后者先弹数据源选择；若当前选中等值线等不适合的对象，仍可在窗口中选择其他可用体网格。

**表单**：数据源及 Zone；切面类型（先支持平面）；定义方式（X/Y/Z 轴对齐或原点＋法向，后者为建议）；位置/原点/法向；显示网格线或表面；可选着色字段和色标。三维几何本身即可创建切片，字段留空表示只看切片网格。

**确认后**：左侧新增“切面 1”；中央在源数据上叠加切面，保留源对象。再次新建得到“切面 2”，各自独立编辑、显隐和删除；选中切面再创建等值线时，将该切面作为可选数据源。

**当前**：来源选择、轴向/位置草稿表单和对象列表存在；任意法向、多个真实切面及渲染待实现。不能把当前示例对象当真实切面。

## 6. 物面/切片等值线与三维等值面

**入口**：“特征 → 等值线 / 等值面”，或“对象 → 新建 → 等值线 / 等值面”。

| 窗口 | 表单 | 确认后的结果 |
| --- | --- | --- |
| 新建等值线 | 数据源选择已有物面或切片；标量字段；一个或多个等值；线颜色、宽度；可选显示标签 | “对象”新增等值线，中央在对应物面/切片上显示线；可继续修改等值、隐藏或导出 |
| 新建等值面 | 数据源选择三维体网格；标量字段；一个或多个等值；颜色、不透明度、边线 | “对象”新增等值面，中央叠加三维面；不覆盖源网格与其他等值面 |

**校验**：字段必须是适用的标量；无字段时解释原因。可显示该字段真实范围，但不能在未读取数据时填入假范围。输入矢量时需用户选择已存在的标量或由后端明确支持的分量/模长。

**当前**：来源选择和单个等值草稿表单存在；多等值、真实算法、渲染及导出待接入。

## 7. 表面流线与迹线

### 7.1 表面流线

**入口**：“特征 → 流线”或“对象 → 新建 → 流线”。

**表单**：物面数据源和区域；积分矢量字段；种子方式（单点坐标、线段或视口交互拾取，后两项为建议）；种子位置；积分方向；长度/步数等参数；筛选条件；线宽、颜色或标量着色。积分矢量和显示用标量应分开。

**确认后**：“对象”新增流线，真实积分成功后画布显示曲线；参数可再次编辑；停止原因或筛选结果在任务信息中展示。没有矢量字段时说明“速度大小是标量，需选择速度矢量”。

**当前**：种子坐标、方向和积分字段为草稿；表面约束、筛选、积分与真实显示待实现。

### 7.2 迹线

**入口**：“特征 → 轨迹”。应先确认需求：是导入已有轨迹，还是根据时间序列计算粒子轨迹。前者表单选择轨迹文件、时间与坐标列；后者需要时间序列、矢量场、种子和起止时间。结果在对象列表和视口展示，并与时间轴联动。以上仅为两种待评审路径，不能直接把“迹线”冻结为某一算法。

## 8. 局部点查询

**入口**：“工具 → 探针”进入拾取模式；“面板 → 探针结果”查看结果面板。

**交互**：在真实视口点击网格/切面 → 按需打开探针面板 → 展示坐标、所属数据集/Zone、点或单元 ID、所选字段及当前时间；再次点击可更新或按需求追加记录。未命中或未加载数据时解释原因。

**当前**：有模式切换和结果面板展示接口；真实拾取与字段查询未接入。会议原文直接要求点抓捕，字段查询是建议细化。

## 9. 多文件、时间轴与二维曲线

### 9.1 多文件和动画

- **入口**：“数据 → 导入结果”多选；关系不明确时进入“数据组织”页。独立结果集在数据树并列；时间序列归到同一结果集下。
- **组织表单**：文件、是否参与、排序、时间值及单位；提供上移/下移和检查缺失帧。时间值来自文件或由用户明确输入，不能把文件顺序当作真实物理时间。
- **确认后**：底部时间轴启用首帧、上一帧、播放/暂停、下一帧、末帧和定位；显示真实帧号和时间。切换时统一更新视口、字段和有效的派生对象状态。
- **当前**：示例时间轴仅改变 UI 标签，真实时序读取、播放和数据更新未实现。

### 9.2 收敛/残差曲线

- **入口**：“分析 → 收敛曲线”。弹出“导入/选择曲线数据”窗口，选择已有监控文件或结果中的记录。
- **表单**：数据源；横轴为迭代步或时间；纵轴为一个或多个残差/监控量；线型、颜色、可选对数坐标；数据无单位时显示未知。
- **确认后**：打开可停靠的二维曲线面板，显示图例、坐标、缩放和系列显隐；可按后续输出支持导出数据/图像。切换选择不应覆盖三维场景。
- **当前**：只有分析入口，没有实际曲线数据读取和绘图流程。

## 10. 导出

**统一入口**：“数据 → 导出”或“工具 → 特征几何 / 时序动画”。建议先显示对应的导出设置窗口，再打开系统保存文件窗口；当前直接进入保存窗口，仅发出请求。

| 导出 | 设置窗口内容 | 选择路径并确认后 |
| --- | --- | --- |
| 数据/格式 | 结果集、Zone/几何、变量、时间范围；目标 Tecplot/CGNS/Plot3D 及其实际支持子集 | 提交导出任务，显示进度；完成后提示真实文件路径，失败时显示原因 |
| 特征几何 | 已计算的等值线、等值面、流线等对象；目标格式、字段保留选项 | 仅真实几何可导出；草稿提示先计算，不能声称生成文件 |
| 图片 | 当前视图、分辨率、背景、图片格式 | 保存当前真实视图，成功后给出路径 |
| 动画 | 时间范围/步长、帧率、尺寸、图像序列或支持的编码格式 | 导出任务逐帧进度及错误；允许取消并说明已有输出的处理方式 |

**当前**：有文件选择和待接入请求，没有真实输出、编码或格式兼容性验证。

## 11. 分析扩展：单列而非前置依赖

下列功能来自会议中的数据智能处理，可从“分析”进入；均使用已有外部结果，不要求先在本软件配置工况。

| 功能入口 | 建议窗口/表单 | 确认后的界面 |
| --- | --- | --- |
| 六分量汇总 | 本地表格文件、状态列、力/力矩或系数列、单位、坐标系和参考量映射 | 可编辑映射的数据预览及结果表；缺失列提示，不推断单位 |
| 公式与舵效 | 选择已导入结果表、状态配对、基准状态、公式和输出列 | 校验通过后形成新结果列，展示计算来源；具体公式和配对方法待确定 |
| 系列线 | 数据表、横轴、纵轴、分组变量、排序和显示样式 | 打开二维图表，可切换系列和导出；不改变三维场景 |
| AI 气动预测 | 数据表、特征/标签、训练与验证划分、模型配置；具体方案另评审 | 训练任务及评估结果窗口、预测表和模型来源；精度指标及数据要求待明确 |

这些窗口目前尚无实际业务实现。DeepSeek 辅助入口与 AI 模型训练/预测不是同一功能。

## 12. 实施顺序及验收

1. **第一批：数据导入、数据树、网格/云图、相机及色标。** 从本地导入一份有场结果和一份仅网格结果，分别验证字段可用性与提示。
2. **第二批：切面、等值线/面、对象管理、导出。** 同一数据创建两个切面，各自编辑和显隐；在其中一个切面提取标量等值线；取消创建不遗留假结果。
3. **第三批：表面流线、探针、时序和曲线。** 验证标量不能充当积分矢量；有/无时间序列及缺失字段均有正确提示；长任务可查看状态。
4. **第四批：多状态分析和 AI。** 先明确数据格式、单位、坐标系及评价方式，再实现业务。

每一项验收都区分：入口是否可点击、表单是否保存、请求是否到服务、算法与文件是否真实正确。示例数据只验证前两者，不代表读取或数值验收。Windows VS2017/Qt 5.12/VTK 8.2 Debug 的原生构建与界面验证按仓库约定执行。
