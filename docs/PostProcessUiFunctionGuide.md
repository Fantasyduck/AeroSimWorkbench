# 后处理功能与界面交互说明

## 1. 工作台与使用范围

后处理工作台用于查看已有计算结果，支持独立打开，也可以从主界面进入。计算进行时，用户可以打开此前已经生成的结果。工作台围绕结果导入、三维查看、特征分析、查询和成果输出组织。

主要工作过程：

1. 打开后处理工作台，导入一个或多个结果集。
2. 在数据面板选择流场、物面、区域或字段，在三维视图中查看。
3. 按需要创建云图、切面、等值线、等值面、流线或迹线，并查看查询结果。
4. 查看系数表，调整视图及对象样式，保存截图或动画。

## 2. 界面组成

| 区域 | 用途 |
| --- | --- |
| 顶部菜单 | 按“数据、显示、特征、输出、工具”组织功能。 |
| 左侧数据面板 | 展示结果集及其流场、物面、区域、字段和时间信息。 |
| 左侧对象面板 | 管理当前创建的云图、切面、等值线、等值面、流线和迹线等对象。 |
| 中央三维视图 | 展示结果、派生对象以及方向辅助，支持视图交互。 |
| 底部时间轴 | 有可用时间序列时切换和播放；没有时置灰。 |
| 探针结果面板 | 查看取点结果，可关闭并再次打开。 |
| 状态栏 | 显示当前操作模式和简短提示。 |

数据和对象面板可以分别关闭，通过“工具”页的对应按钮重新打开。探针结果也有独立入口。左侧不再设置重复的“视图”面板。

## 3. 数据与结果集

### 3.1 导入结果集

点击“数据 → 导入结果集”，打开导入窗口，输入或确认结果集名称，分别选择：

| 文件 | 用途 |
| --- | --- |
| CGNS | 流场及其网格、区域、边界和场变量。 |
| TEC | 物面网格及物面变量。 |
| CSV | 边界及总体的力和力矩系数。 |

可以先选择其中一种或几种文件，之后再给该结果集补充其他文件；也可以新建多个结果集。、

导入窗口显示所选路径、文件用途及状态；至少选择一个文件才能提交。导入或读取失败时应说明原因，允许重新选择；未成功读取的文件显示为待处理或失败，不展示成已经可分析的数据。

### 3.2 数据面板

- 以结果集为单位组织已导入内容，展开查看文件、网格类型、Zone、边界和可用字段。
- 点击结果集或其中的对象，显示名称、来源及当前选择；多个结果集可以分别选择和管理。
- 对可显示的区域支持显隐、选择和样式调整。列表选择与三维视图中的对应对象高亮联动；从视图选中对象后，数据面板定位对应项。
- 操作依赖于当前选择和可用数据。条件不满足时，相关按钮置灰并说明原因；没有数据时不显示虚构字段或结果。

### 3.3 系数表

点击“数据 → 系数表”，打开独立窗口；可以查看当前结果集关联的 CSV，也可以在窗口内单独选择 CSV。

- 按文件提供的列展示边界编号、名称、升阻力系数、三方向力／力矩系数及总体记录，支持排序和查看来源。
- 选择多组系数时可并列比较；绘制比较图时明确选择横轴工况和纵轴系数。
- 在能够确定边界对应关系时，选择表格行可关联查看对应区域。

## 4. 三维视图基础操作

### 4.1 选择与交互模式

“显示”页提供选择、框选、平移、缩放和旋转模式。当前模式应有清楚的选中状态和操作提示。选择或框选时，视图中的选中对象应有明显反馈，数据面板或对象面板同步展示当前选择。

| 操作 | 交互要求 |
| --- | --- |
| 选择 | 单击视图中的可选对象；列表选择与视图高亮联动。 |
| 框选 | 拖动框选区域，选择范围内支持选择的对象。 |
| 旋转 | 拖动旋转视角；旋转中心可以设置。 |
| 平移 | 拖动移动视图；鼠标中键可用于平移。 |
| 缩放 | 使用滚轮或缩放模式改变视图比例。 |

### 4.2 常用视角与视图恢复

- **前视、右视、俯视**：点击对应按钮切换观察方向。
- **方向辅助**：在视图中显示坐标方向，帮助判断当前朝向。
- **视角方向球**：在三维视图角落显示带颜色和方向标识的三维球形导航控件。拖动方向球可以连续调整观察角度；点击相应方向可切换到前、后、左、右、上、下等标准视角。方向球随当前视角同步变化，帮助用户识别方向。
- **适配视图**：将当前可见内容调整到合适的中心和大小。
- **聚焦选中对象**：围绕选中的区域或对象调整中心和大小，便于找回离开视野的对象。
- **旋转中心**：选择使用选中对象中心，或输入 X、Y、Z 坐标；确认后用于后续旋转。

方向球与直接拖动三维视图都用于调整观察视角，不改变流场或物面原始数据。具体配色及方向标识的呈现可结合原型确定；当前界面中的方向文字不能代替可交互的方向球。

### 4.3 背景与对象显示

点击“显示 → 视口背景”，可选择预设或自定义颜色，选择单色或上下渐变；提供恢复默认。默认使用 ParaView 风格的蓝灰渐变。应用后更新当前视图，取消不应用此次修改。

选中数据区域或对象后，可打开“对象样式”窗口，设置显隐、边界轮廓线／表面／线框／表面加边线／点等显示方式、颜色和不透明度。对不同对象分别设置；显示设置不改变原始文件。

### 4.4 坐标尺

参考 Tecplot 360 提供三维坐标尺，显示坐标轴方向、刻度和数值，辅助用户判断空间位置和尺度。提供显示／隐藏入口，并可设置轴名称、刻度、数值显示、颜色及字体；随视图和数据范围更新。坐标尺与视角方向球分别用于尺度和方向提示。

## 5. 云图与特征对象

### 5.1 云图和色标

选中流场、物面或切面，点击“显示 → 新建云图”，选择对象和可用字段。设置色谱、色标显隐、数值范围及透明度；范围支持自动和手动。确认后云图出现在视图和对象面板中，可再次选择、编辑或隐藏。

TEC 提供物面网格和字段，用户选择字段后显示物面云图；它不是一张固定的云图图片。同一数据源可按不同字段或显示设置创建多个云图。界面只列出所选数据实际提供的字段和可用分量。

### 5.2 切面

选中三维流场，点击“特征 → 添加切面”，或在对象面板选择“新建 → 添加切面”。选择数据源后，设置切面位置、方向，必要时填写原点和法向；选择表面、网格线等显示方式及可用字段。

确认后，切面在视图和对象面板中显示。可以创建多个切面；双击对象可重新编辑参数，单个切面的显隐或删除不影响其他切面。

### 5.3 等值线和等值面

- **等值线**：选择物面或已有切面及标量字段，填写一个或多个等值，设置颜色、线宽等样式。
- **等值面**：选择三维流场及标量字段，填写等值，设置颜色和透明度等样式。

确认后生成相应对象，可在对象面板编辑、显隐或删除。缺少符合条件的数据或字段时，界面说明需要什么。

### 5.4 流线

选中可用的体场或物面，点击“特征 → 流线”，确认数据源和速度矢量，在参数窗口设置：

- 点或线种子的位置、线种子终点和种子数量；
- 积分方向、步长、最大长度或步数；
- 线条颜色、按字段着色等显示方式。

确认后，流线对象出现在视图和对象面板中，可继续编辑、显隐和删除。只有速度大小或马赫数、没有可用速度矢量时，界面应提示原因。

### 5.5 迹线

“特征 → 迹线”与流线分开。选择具有有效时间信息的连续速度场后，设置粒子释放位置、释放时间、跟踪时间范围和显示样式；缺少所需时间帧或速度矢量时说明原因。已有轨迹文件的查看方式以实际输入范围为准。

### 5.6 对象管理

对象面板列出派生对象，显示名称、来源、显隐及草稿／结果状态。支持选择、新建、双击编辑参数、调整样式、显隐和删除；取消新建时不留下未确认对象。处理尚未完成、失败或仍为草稿时，要清楚标识，不能显示成已完成的真实结果。

## 6. 探针查询

1. 选中可查询的流场或物面，点击“工具 → 探针”，进入取点模式。
2. 在三维视图点击位置。命中后自动打开“探针结果”面板，显示位置、所属结果集／区域及该位置可用字段的值；未命中时提示用户。
3. 面板可以关闭，通过“工具 → 探针结果”重新打开；重新打开不改变当前鼠标模式。

目前结果面板是单次结果显示，多点记录、复制及导出可作为后续交互扩展。没有真实取点结果时，面板展示空状态。

## 7. 时间轴

底部时间轴提供首帧、上一帧、播放／暂停、下一帧、末帧和拖动定位，并显示当前帧及已知时间。无可用时间序列时，时间轴及播放按钮置灰；时间未知时标注未知，不根据文件名推定物理时间。顶部不设置独立的“时间序列”按钮。

## 8. 输出与保存

“输出”页提供截图和动画的保存入口。默认保存在后处理目录，允许选择其他位置；截图或动画保存后，在主界面的后处理产物列表中显示并提供打开入口，界面之间通过文件交互。

| 功能 | 设置与交互 |
| --- | --- |
| 保存截图 | 点击“保存图片”，设置图片格式、宽高和背景，选择保存位置。 |
| 保存动画 | 存在有效时间序列时可选择帧范围、帧率、宽高和输出形式。 |

截图的保存及其在主界面列表管理是明确场景，动画也作为列表管理的产物提出。格式、分辨率、帧率和动画编码等是界面设置方案，具体支持范围需要确定。无可用时序数据时动画入口置灰。预览和已保存的文件应明确区分；成功显示保存路径，失败显示原因。

## 9. 界面示例与当前边界

“工具 → 界面示例”可用于查看结构或非结构网格场景的界面交互。示例中的对象、字段和时间帧必须标明为示例，不能与真实导入结果混淆。

目前界面已具备结果集导入窗口、系数表入口、对象参数草稿、背景设置、探针结果面板和输出设置窗口等交互框架。真实数据导入、三维视图操作、数值查询、特征生成、表格内容及文件输出仍需逐项接入和验证；部分按钮与表单只提供界面草稿。用户只能对已具备条件的真实数据执行对应功能。

## 10. 版本范围

- **版本范围**：后处理考虑完整版和面向需求的交付版本。哪些功能在各版本中提供、隐藏或裁剪，需要逐项确定；现阶段不把未列明的差异作为既定方案。
