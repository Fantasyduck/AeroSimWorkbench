# 可视化分析台：数据导入、对象分析与渲染

## 1. 整体流程

本工作台统一命名为 **可视化分析台**，用于查看已有计算结果，可独立打开或从主界面进入。工作台围绕数据导入、三维查看、特征分析、查询和输出组织；顶部使用“数据与显示”“特征”“工具与输出”，数据面板管理数据集及区域，对象面板管理派生对象，中央为三维视口，底部为时间轴。

目标流程是：选择网格和结果文件 → 读取并识别数据集、区域和字段 → 选择区域或已有对象 → 设置云图、切面、等值线、等值面、流线或迹线 → 查看、查询和输出。不同格式由各自的读取适配器转换为 VTK 内存数据；再次导入时可选择“追加显示”或“替换现有数据”。

**当前实现边界**：本阶段主要完成界面和交互草稿。文件选择后显示“等待读取”，结构网格、非结构网格和多文件示例均为明确标注的 UI 示例。真实文件读取与配对、字段元数据、VTK 三维渲染、特征计算、探针拾取和文件输出尚未接入；方向导航及其操作请求不代表真实相机已联动。下文描述目标功能和已考虑的 UI 逻辑，不能视为后台已实现或公共接口已定案。

## 2. 文件输入与内存数据

### 2.1 输入格式

| 格式 | 内容 | 读取方式 |
| --- | --- | --- |
| VTK：`.vtk`、`.vti`、`.vtu`、`.vts`、`.vtr`、`.vtp` 等 | 规则网格、结构化网格、非结构网格及表面几何等数据 | 根据文件类型选择对应的 VTK 读取器。 |
| CGNS：`.cgns` | 结构化或非结构化网格、区域、边界及流场变量 | 使用 CGNS 读取适配器，读取网格与可用字段。 |
| Plot3D | 网格坐标及流场数据，可能分别保存在不同文件中 | 使用 Plot3D 读取适配器，选择并关联对应文件。 |
| Tecplot 文本：`.tec`、`.dat` | 网格、区域及物理变量 | 计划使用 Tecplot 文本读取适配器。 |
| Tecplot 二进制：`.plt` | Tecplot 二进制数据 | 文件选择器提供入口；读取能力和支持范围尚待确定，不与文本读取器等同。 |

导入窗口支持一次选择多个文件、移除所选文件并显示路径。首次导入无需选择导入方式；已有数据时可选：

- **追加显示**：保留现有数据，新数据读取成功后加入，并各自管理名称、区域、字段、显隐及显示设置。
- **替换现有数据**：请求用新数据替换现有数据；读取成功前保留现有数据，失败时保留原数据并提示原因。

Plot3D 常见的 `.xyz` 网格文件提供坐标和网格，`.q` 结果文件提供流场量；只查看网格可单独选择网格文件，查看流场需关联匹配的网格和结果文件。扩展名不能证明文件内容或配对正确，多个网格与结果的配对交互及校验尚待读取服务设计。导入、追加和替换目前仅生成待处理请求，不表示读取成功。
### 2.2 内存数据组织

不同格式通过各自的读取适配器转换为 VTK 内存数据，统一管理数据集、区域、字段和显示状态。单个网格采用与其类型对应的 `vtkDataSet` 数据对象；包含多个区域的数据可使用 `vtkMultiBlockDataSet` 组织。不同来源的数据通过统一的数据集管理方式进入后续显示和分析流程。

内存数据主要包括：

| 内容 | 说明 |
| --- | --- |
| 几何与网格 | 节点坐标、单元、网格类型及拓扑关系。 |
| 区域 | 数据集中的 Zone、网格块、边界及其名称。 |
| 物理字段 | 温度、压力、速度等实际存在的变量。 |
| 字段属性 | 字段名称、分量数量、节点或单元位置、已知单位。 |
| 数据来源 | 原始文件、数据集名称及已知时间信息。 |

### 2.3 多文件、数据集和区域

以**数据集**作为选择和管理的主要单位：一个文件可包含多个区域，也可能由多个配套文件共同构成一个数据集；文件与数据集并非必然一一对应。数据面板应保留数据集与来源文件的对应关系，并按数据集 → 区域 → 该区域可用字段展示，例如：

```text
数据集 A（来源：网格文件、结果文件）
├─ 流场区域
│  └─ 可用字段：压力、温度、速度
└─ 翼面区域
   └─ 可用字段：压力、摩擦系数
```

字段名称可在多个区域中出现或共享，但各区域的数据、字段位置和可用性可能不同；数据集级的字段总览可作为补充，不能替代区域与字段的对应关系。多文件示例已在区域下展示示例字段；真实区域及字段树需等读取服务提供。界面中的待导入文件不进入可分析来源列表。
### 2.4 属性字段识别

文件读取后，遍历各数据集及其区域中的字段，识别字段名称、分量数量和所属位置，在数据树中按区域展示，并提供给云图、切面、等值面和流线等功能选择。

- **标量字段**：单分量数据，例如温度、压力、密度和马赫数，可用于云图或等值特征。
- **矢量字段**：三个分量组成的数据，例如速度矢量，可用于流线。
- **分量组合**：当速度以 U、V、W 等独立字段保存时，可根据名称提供组合建议，由用户确认三个分量。
- **字段位置**：区分节点字段和单元字段，界面应显示其所属位置。
- **字段差异**：不同结果或区域可能具有不同字段，界面只显示对应数据中实际存在的变量；未知的物理含义或单位不自行推断。

### 2.5 VTK 可视化流程

```text
文件 → 读取器 / 适配器 → VTK 内存数据 → Filter → Mapper / Actor → Renderer / Camera → 三维视口
```

| 环节 | 作用 |
| --- | --- |
| Reader / 适配器 | 读取不同格式的网格、区域和字段。 |
| VTK 内存数据 | 保存网格与物理字段，供显示和分析使用。 |
| Filter | 对数据进行切面、等值面、流线等处理。 |
| Mapper / Actor | 设置数据的颜色、显示方式和场景对象。 |
| Renderer / Camera | 组织三维场景，设置观察位置和方向。 |
| 三维视口 | 显示最终画面，接收选择、旋转、平移和缩放操作。 |

温度云图选择温度标量字段，通过色谱显示数值分布；流线选择速度矢量，并设置种子位置和积分方向。不同区域和对象可独立选择字段与显示方式。


## 3. 派生对象与字段选择

对象面板提供新建、选择、双击编辑、样式、显隐和删除。选择数据源时，按数据集、符合对象要求的区域或已有对象、该来源的可用字段逐级确定；从已有选择进入时尽量带入当前上下文。不同功能的字段要求不同，不能把速度大小当作速度矢量；没有合适数据或字段时说明原因。当前仅管理界面对象和参数草稿，不生成真实结果；取消未经应用的新建草稿应移除该草稿。

| 对象 | 来源及字段 | 核心属性与选择逻辑 |
| --- | --- | --- |
| 云图 | 区域或可着色对象、标量字段 | 选择配色方案、自动或手动范围、图例显隐。 |
| 切面 | 三维体区域；建立几何时不要求字段 | 选择 X/Y/Z 方向与位置，或输入原点和非零法向；选择显示方式，按需选择着色字段。切换定义时只显示相关输入。 |
| 等值线 | 物面或切面及标量字段 | 指定一个或多个等值，或设置最小值、最大值及等值数量；设置线宽及单色／标量着色。 |
| 等值面 | 三维体区域及标量字段 | 指定最多三个等值，设置不透明度及单色／标量着色；着色字段可以不同于提取字段。 |
| 流线 | 体区域或表面及可用速度矢量 | 根据来源选择体流线或表面流线；设置单点或线段种子、积分方向、步长、最大长度和步数，选择单色或标量着色。 |
| 迹线 | 三维体区域、速度矢量及多个有效时间帧 | 区分粒子路径与连续释放迹线，设置单点或线段种子、释放与结束时间及时间积分；连续释放还需指定频率。 |

切面、流线和迹线按定义或种子方式显示对应输入；线段种子两端不能重合。等值线范围的最小值须小于最大值；等值面附加等值应为有效数字。积分步长、线宽及数量须为正数，迹线结束时间须晚于释放时间。当前时间范围是否属于真实数据、节点／单元位置兼容性，以及视口拾取仍需服务接入后校验。独立 U/V/W 分量可手动组合，须由用户确认其数据位置一致。

### 3.1 云图与色标

- **字段**决定显示的物理量，**配色方案**决定数值如何映射到颜色；蓝白红方案的白色不保证对应零。
- **自动范围**计划采用当前对象、字段及时间步的实际最小值和最大值；**手动范围**固定映射上下限，用于比较不同结果或时间步，最小值必须小于最大值。
- **数据实际值域**与手动颜色范围分别显示；范围外数值按端点颜色显示，不修改原始数据。图例显隐不改变对象显隐。真实范围计算及着色仍待接入。

## 4. 视图、查询和输出

- 视图提供选择、框选、旋转、平移和缩放模式，以及前视、右视、俯视、适配视图、聚焦选中对象和旋转中心。右上角 XYZ 方向导航可拖动预览朝向或点击方向发送标准视角请求；真实相机和方向导航的双向同步待接入。
- 支持视口背景预设、自定义颜色和渐变设置，以及对象的显隐、表面／线框等样式、颜色和不透明度草稿。坐标尺提供入口，实际刻度和数据范围尚待接入。
- 探针进入取点模式，探针结果面板可独立打开；真实拾取和字段值查询待接入。时间轴仅在有可用时间序列时启用，时间未知时不得推断物理时间。
- 图片和时序动画提供输出设置与路径选择入口；实际文件生成和主界面产物管理尚待接入。动画需要有效时间数据。
- DeepSeek 入口用于基于当前选择组织后处理任务，目前为界面入口和请求，实际任务服务尚待接入。

派生对象的 UI 设计与参考来源见 [派生对象 UI 核心设计](PostProcessFeatureUiDesign.md)。本工作台只抽取所需核心交互，不要求完整复制 Tecplot 360 的所有功能。

## 5. 三维渲染基础概念

| 概念 | 含义 | 在可视化分析台中的作用 |
| --- | --- | --- |
| Viewport，视口 | 窗口中用于显示三维画面的区域。 | 展示流场、网格、云图和特征对象，接收鼠标交互。 |
| Viewpoint / Camera，观察点 / 相机 | 观察者的位置、朝向和观察方式。 | 控制旋转、缩放、前视、俯视及视图恢复。 |
| 视锥 | 相机能够看到的空间范围，由观察范围及前后裁剪面决定。 | 限定显示范围，避免模型被不合适的裁剪面截断。 |
| 变换矩阵 | 用矩阵表示平移、旋转、缩放及投影等变换。 | 将模型坐标逐步转换为屏幕位置，完成视角和对象变换。 |
| 坐标系 | 描述位置和方向的参照，包括模型、世界、相机和屏幕坐标。 | 用于对象定位、切面设置、探针查询和方向辅助。 |
| Z-buffer，深度缓冲 | 记录画面中像素的深度信息。 | 判断物体前后关系，使近处表面遮挡远处表面。 |
| 消隐 | 处理被其他物体或表面遮挡的不可见部分。 | 保证三维模型的遮挡关系正确。 |
