# 可视化分析台数据导入与渲染

## 1. 整体流程

可视化分析台支持导入不同格式的网格和流场文件，由对应的读取适配器读取坐标、网格、区域及物理字段，组织为统一管理的 VTK 内存数据；在三维视图中显示后，用户可选择实际存在的字段进行温度云图、切面、等值面和流线等分析。首次导入时直接显示，已有结果时再次导入，用户可选择 **Replace** 替换现有结果，或选择 **Append** 追加结果并同时显示；追加的结果分别保留名称、区域、字段、显隐及显示设置。

## 2. 文件输入与内存数据

### 2.1 输入格式

| 格式 | 内容 | 读取方式 |
| --- | --- | --- |
| VTK：`.vtk`、`.vti`、`.vtu`、`.vts`、`.vtr`、`.vtp` 等 | 规则网格、结构化网格、非结构网格及表面几何等数据 | 根据文件类型选择对应的 VTK 读取器。 |
| CGNS：`.cgns` | 结构化或非结构化网格、区域、边界及流场变量 | 使用 CGNS 读取适配器，读取网格与可用字段。 |
| Plot3D | 网格坐标及流场数据，可能分别保存在不同文件中 | 使用 Plot3D 读取适配器，选择并关联对应文件。 |
| Tecplot 文本：`.tec`、`.dat` | 网格、区域及物理变量 | 使用 Tecplot 文本读取适配器。 |

Tecplot 二进制 PLT 与文本格式的读取方式不同，暂不纳入首批读取范围；VTK 8.2 的 `vtkTecplotReader` 用于读取 ASCII Tecplot 文件。[VTK 8.2 Tecplot 读取器](https://vtk.org/doc/nightly/release/8.2/html/classvtkTecplotReader.html)

### 2.2 内存数据组织

不同格式通过各自的读取适配器转换为 VTK 内存数据，统一管理数据集、区域、字段和显示状态。单个网格采用与其类型对应的 `vtkDataSet` 数据对象；包含多个区域的数据可使用 `vtkMultiBlockDataSet` 组织。不同来源的数据通过统一的数据集管理方式进入后续显示和分析流程。

结构化网格与非结构化网格分别保留适合自身的 VTK 数据类型，不强制全部转换为非结构网格，也不需要生成一个新的中间文件。每份数据保持独立，支持分别选择、显示、隐藏和设置样式。

内存数据主要包括：

| 内容 | 说明 |
| --- | --- |
| 几何与网格 | 节点坐标、单元、网格类型及拓扑关系。 |
| 区域 | 数据集中的 Zone、网格块、边界及其名称。 |
| 物理字段 | 温度、压力、速度等实际存在的变量。 |
| 字段属性 | 字段名称、分量数量、节点或单元位置、已知单位。 |
| 数据来源 | 原始文件、数据集名称及已知时间信息。 |

### 2.3 属性字段识别

文件读取后，遍历各数据集及其区域中的字段，识别字段名称、分量数量和所属位置，在数据树中按区域展示，并提供给云图、切面、等值面和流线等功能选择。

- **标量字段**：单分量数据，例如温度、压力、密度和马赫数，可用于云图或等值特征。
- **矢量字段**：三个分量组成的数据，例如速度矢量，可用于流线。
- **分量组合**：当速度以 U、V、W 等独立字段保存时，可根据名称提供组合建议，由用户确认三个分量。
- **字段位置**：区分节点字段和单元字段，界面应显示其所属位置。
- **字段差异**：不同结果或区域可能具有不同字段，界面只显示对应数据中实际存在的变量；未知的物理含义或单位不自行推断。

### 2.4 VTK 可视化流程

```text
文件 → 读取器 / 适配器 → VTK 内存数据 → Filter → Mapper / Actor → Renderer / Camera → 三维视口
```

| 环节 | 作用 |
| --- | --- |
| Reader / 适配器 | 读取不同格式的网格、区域和字段。 |
| VTK 内存数据 | 保存网格与物理字段，供显示和分析使用。 |
| Filter | 对数据进行切面、等值面、流线等处理。 |
| Mapper / Actor | 设置数据的颜色、显示方式和场景对象。 |
| Renderer / Camera | 组织三维场景，设置观察位置和方向。 |
| 三维视口 | 显示最终画面，接收选择、旋转、平移和缩放操作。 |

温度云图选择温度标量字段，通过色谱显示数值分布；流线选择速度矢量，并设置种子位置和积分方向。不同区域和对象可独立选择字段与显示方式。

## 3. 三维渲染基础概念

| 概念 | 含义 | 在可视化分析台中的作用 |
| --- | --- | --- |
| Viewport，视口 | 窗口中用于显示三维画面的区域。 | 展示流场、网格、云图和特征对象，接收鼠标交互。 |
| Viewpoint / Camera，观察点 / 相机 | 观察者的位置、朝向和观察方式。 | 控制旋转、缩放、前视、俯视及视图恢复。 |
| 视锥 | 相机能够看到的空间范围，由观察范围及前后裁剪面决定。 | 限定显示范围，避免模型被不合适的裁剪面截断。 |
| 变换矩阵 | 用矩阵表示平移、旋转、缩放及投影等变换。 | 将模型坐标逐步转换为屏幕位置，完成视角和对象变换。 |
| 坐标系 | 描述位置和方向的参照，包括模型、世界、相机和屏幕坐标。 | 用于对象定位、切面设置、探针查询和方向辅助。 |
| Z-buffer，深度缓冲 | 记录画面中像素的深度信息。 | 判断物体前后关系，使近处表面遮挡远处表面。 |
| 消隐 | 处理被其他物体或表面遮挡的不可见部分。 | 保证三维模型的遮挡关系正确。 |
