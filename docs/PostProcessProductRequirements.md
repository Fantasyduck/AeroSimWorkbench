# 后处理模块功能与实现要求

## 1. 模块定位

后处理用于独立打开已有结果，完成网格与场数据显示、空间特征提取、结果查询、对比和导出。使用者不需要先在本软件创建工程、配置工况或执行计算。主界面可以提供结果入口，并管理需要登记的图片、动画等产物；独立使用时应允许直接选择文件、直接保存结果。

使用主线：

```text
选择已有结果 → 识别与组织数据 → 查看网格和场 → 查询或创建特征
                                  ↓
                          显示、对比、输出
                                  ↓
                     独立保存 / 可选登记到主界面
```

## 2. 示例数据及输入边界

### 2.1 三类结果文件

| 文件 | 样例中实际观察到的内容 | 在产品中的用途 |
| --- | --- | --- |
| `*_flowfield_step100.cgns` | HDF5 格式的 CGNS，含三维非结构 Zone、体单元、坐标、边界及 FlowSolution 场数组 | **空间后处理的主输入**：显示体网格/流场，进行切面、等值面、探针和流线等 |
| `*_boundary_step100.tec` | Tecplot 文本，按 `wing_down`、`wing_edge`、`wing_up` 三个边界分区，包含网格、坐标及物理场变量 | **物面结果输入**：导入并用于物面查看、物面云图及边界结果核对 |
| `*_force.csv` | `BC index`、`wallname`、`Cl`、`Cd`、`Cx`、`Cy`、`Cz`、`Cmx`、`Cmy`、`Cmz`；三条翼面记录及 `ALL / ALL_WALL` 总计 | **结果表格**：按边界展示系数、查看总计、跨结果对比；不作为网格或场数据 |

后处理明确需要直接导入并使用 **CGNS、TEC 和 CSV 三类结果文件**：CGNS 是网格和流场的主要空间输入，TEC 提供物面网格及场结果，CSV 提供边界和总体力系数表。

### 2.2 流场 CGNS 的已观察结构

本次检查 `Ma5/h5000` 组的流场 CGNS：

- 文件约 16.2 MB，HDF5 容器内的 CGNS 库版本字段约为 **3.31**；包含一个 `Base` 和一个名称为 `Zone` 的非结构 Zone。
- Zone 数据给出 **107,973 个节点、257,817 个体单元**。体单元包含 74,142 个四面体、3,503 个金字塔、179,721 个棱柱和 451 个六面体，属于混合单元网格。
- 有 `GridCoordinates/CoordinateX/Y/Z`；`FlowSolution` 下有 `x/y/z`、`rho_dim`、`u_dim`、`v_dim`、`w_dim`、`p_dim`、`mach`，各数组长度均为 107,973。本例的 `FlowSolution/x/y/z` 与坐标数组逐项相同，不能把它们默认当作额外的温度或速度字段。
- `u_dim/v_dim/w_dim` 可作为候选速度分量，但**变量单位、坐标系及矢量分量约定仍须确认**；`rho_dim`、`p_dim`、`mach` 是本例实际出现的字段。本例未观察到温度字段，UI 不能凭示例名称虚构温度数据。
- `FlowSolution` 下未看到显式 `GridLocation` 子节点。数组长度与节点数一致是事实；读取器应结合 CGNS 语义和文件元信息正确判定关联，不能把“长度相同”当成适用于所有文件的通用规则。
- `ZoneBC`/单元分区包含 `farfield`、`symmetry`、`wing_down`、`wing_edge`、`wing_up` 等信息，其中 symmetry 有三角形和四边形边界分区，翼面为三角形边界分区。实际边界类型和值应由 CGNS 内容读取，不仅靠名称猜测。

`Ma6/h6000` 组也有流场 CGNS，但本次未对其完整内部结构及数值逐项解析；不能只因为命名相似就宣称两份数据内容相同。本例只有非结构样例，**结构化 CGNS 仍需另备样例验证**。

### 2.3 边界 TEC 与力系数 CSV

所检查 TEC 首行变量为 `x y z rho_dim u_dim v_dim w_dim p_dim mach`，有三个 `feblock` 边界 Zone：`wing_down`、`wing_edge`、`wing_up`。同组 CSV 中 `BC index` 分别为 `3/4/5`，边界名称相同，另有 `ALL_WALL` 汇总行。这为跨文件展示和核对提供了线索，但正式关联仍应校验数据来源、边界身份及映射规则，不能仅凭文本名称作永久契约。

CSV 的 `Cx/Cy/Cz/Cmx/Cmy/Cmz` 可展示为三方向力与力矩系数，`Cl/Cd` 是额外的升阻力系数列；其方向、正负号、参考量和单位应以数据定义确认。本例包含边界系数及总计。

## 3. 用户工作流程

1. 打开独立后处理工作台，点击“导入结果集”，指定结果集名称及 CGNS、TEC、CSV 文件；也可由主界面传入已完成结果的路径。
2. 程序读取成功后，在结果树显示已导入的文件及其内容；对空间数据展示网格类型、Zone、边界和实际字段，中央显示几何并自动调整视角。
3. 用户选择流场、某个翼面或其他边界，切换网格/表面/边线，选择实际字段显示云图或查看局部数值。
4. 用户基于所选数据创建切面、等值线/面或流线；每个派生对象独立调整参数、显隐和删除。
5. 需要查看气动系数时，选择结果集并点击“系数表”；也可在系数表窗口单独导入 CSV。
6. 结果满足要求后，保存截图或动画；产物放在后处理目录，在主界面列表中显示并可打开。

界面应允许结果加载、显示和操作过程中的取消、错误反馈及状态查看，不将预览图或界面草稿当成真实结果。

## 4. 主要功能：界面交互与后台逻辑

### 4.1 结果文件选择和组织

**UI 交互**

- 点击“数据 → 导入结果集”，打开导入窗口：填写结果集名称，分别通过文件选择控件指定 CGNS 流场、TEC 物面和 CSV 系数文件，显示各文件的路径、用途和导入状态。
- 三种文件可分次导入；至少选择一个文件后即可创建结果集，后续可补充其他文件。用户确认文件归属，文件名前缀可用于推荐关联，不自动认定边界一一对应。
- 支持打开多个独立结果集并在结果树中区分；不同算例、同一算例的时间帧及分区应依据用户指定或可靠元数据区分，不自动视为同一序列。
- 读取期间显示文件和进度；失败时给出文件名、格式/缺失字段等可理解的错误。数据树展示已成功加载的来源、Zone、边界及字段；未读取成功的文件不变成可操作的数据对象。
- 流场结果直接提供空间分析所需的网格和字段；单独的前处理网格文件不作为结果集导入项。缺少某项分析所需字段时，界面说明原因。

**后台逻辑**

- 分别识别和解析 CGNS、TEC、CSV，检查路径、文件完整性、格式结构与支持的版本；读取不应阻塞 UI。
- TEC 读取网格、Zone、坐标及字段，提供物面显示和云图数据；CSV 读取表头、边界记录、系数和汇总行，提供表格与比较数据。
- CGNS 读取器需覆盖样例的 HDF5 容器、非结构 Zone、混合体单元、三角/四边形边界和场数组。结构化 CGNS、其他版本/编码须另有样例和测试，不能由本例推断。
- 明确数据集、文件、Zone、边界、字段、点/单元关联、单位、时间及来源；保留未知值。大量网格与 VTK 对象由实现层管理，不放入公共契约。
- 跨文件关联需要校验结果来源与边界映射；未经验证不按节点或单元顺序拼接数据。
- 为不同结果组分配独立对象和生命周期；读取成功后才能向显示和特征功能提供真实数据。

### 4.2 三维网格、区域和相机

**UI 交互**

- 左侧数据树列出网格、Zone 和边界，可勾选显隐、选择单个区域；提供整体与局部的边界轮廓线、表面、网格线、线框和颜色设置。
- 列表选中某个翼面时，中央对应几何高亮；直接点击几何时，列表同步定位到可识别对象。
- 提供平移、缩放、旋转、常用视图、方向辅助、旋转中心及背景颜色设置；明确“适配全部”和“聚焦选中对象”两个入口。找回对象必须同时调整相机中心和大小。两个入口的命名和布局是设计选择，核心要求是能按希望查看的网格找回合适的中心和显示大小。
- 区域颜色和显示样式是视图状态；应用这些设置不改原始 CGNS、TEC 或 CSV。

- **坐标尺**：参考 Tecplot 360 提供坐标轴、刻度和数值的显示／隐藏及样式设置，随视图和数据范围更新。

**后台逻辑**

- 将混合单元和边界按真实拓扑转换为可显示数据；区分体网格、外表面和边界分区，避免把所有边界静默合并。
- 统一管理 VTK 视口、场景对象、相机和选择映射；列表项与显示对象通过稳定的轻量标识关联。
- 适配对象包围盒并计算合理中心和视距；多个对象可同时存在，更新或删除一个对象不清空其他对象。
- 渲染对象及 Widget 操作在 GUI 线程；读取、提取等耗时操作放在后台，跨线程传轻量消息并明确生命周期。

### 4.3 物理场和云图

**UI 交互**

- TEC 保存物面网格和字段；导入后用户选择实际标量字段，程序按数据和色标绘制物面云图。
- 选中流场、物面或已有切面，点击“新建云图”，在窗口中选择数据源、对象、实际存在的字段及其分量/关联；可调整色谱、色标、范围及透明度。用户可基于同一数据源创建多个云图并分别管理。
- 自定义云图使用已有字段和显示设置；公式计算新字段属于另行设计的能力。
- 对示例 CGNS，至少应能识别并供选择 `rho_dim`、`p_dim`、`mach` 和 `u_dim/v_dim/w_dim`；通过明示的矢量分组/分量规则后，才能提供速度矢量或模长。
- 当打开样例 TEC 作为物面补充时，只显示该文件实际带有的字段和边界；缺少温度时不显示一个虚构的温度结果。
- “自动范围”依据真实有效数据，用户可切换手动范围；数据缺失、无效值或字段关联不支持时显示原因。

**后台逻辑**

- 保留原始字段名称、数组类型、点/单元关联、来源和已知单位；重复坐标字段不自动伪装为独立物理变量。
- 根据已确认的规则构建矢量或模长；点/单元字段之间若要转换或插值，明确算法和作用范围，不能静默改变原始数组。
- 计算实际范围并建立颜色映射；源数据、不同 Zone 和不同结果组的显示状态彼此独立。

### 4.4 多截面、等值线和等值面

**UI 交互**

- “特征 → 添加切面”或“对象 → 新建 → 切面”：选择三维数据源、位置和方向，可选择网格线/表面及可用的着色字段；没有标量时仍可查看几何切面。
- 可以同时创建多个截面；每个对象显示名称、来源、状态、显隐，双击重新编辑，删除一个不影响其他切面。
- “等值线”：选择已有物面或切面、标量和等值；“等值面”：选择体网格、标量和等值。参数窗口允许配置样式，缺少对应字段时说明原因。
- 用户确认后，计算中显示任务状态；成功才显示真实几何，失败保留参数并允许重试。草稿和已计算对象应明确区分。

**后台逻辑**

- 根据结构/非结构拓扑和可用字段生成切片、物面/切片等值线和三维等值面；正确处理样例的四种体单元及点/单元字段。
- 独立保存各对象的参数、来源、计算版本、几何句柄和显隐状态；在数据源变化或删除后明确失效与清理策略。
- 对分区接口平滑的范围另行确认：仅显示法向、几何合并还是字段插值不能混为一谈，更不能未经说明修改原始数值。

### 4.5 流线、迹线和局部查询

**UI 交互**

- 选中体场或支持流线计算的物面，点击“流线”，在窗口确认数据源和有效速度矢量；设置点或线种子的位置和数量、积分方向、步长、最大长度及显示样式。点击“生成”后，成功结果显示在视图和对象列表中，可重新编辑、显隐或删除。只有 `mach` 或速度大小时应提示缺少可用速度矢量。
- “探针”模式在真实几何上点选后，按需打开结果面板，显示位置、所属数据/边界和实际字段；未命中要有反馈。
- “迹线”与流线分别提供入口。计算粒子随时间的运动路径时，选择具有时间信息的连续速度场，设置粒子释放位置、释放时间、跟踪时间范围和显示样式；缺少有效时间帧或速度矢量时说明原因。已有轨迹的查看需以实际轨迹数据格式为依据。

**后台逻辑**

- 检查矢量分量、关联方式和物面约束，完成种子、积分与筛选；记录停止原因及结果来源。自动筛选的规则和验收条件需另行确定。
- 拾取数据位置后读取对应字段，明确点/单元取值或插值语义；不得生成示例查询值冒充真实数据。
- 本样例没有经过核实的多时间帧或轨迹文件，不能用它验收非定常迹线或时序粒子追踪。

### 4.6 CSV 系数表及跨结果比较

**UI 交互**

- 选中结果集后点击“系数表”，打开独立表格窗口；窗口也提供“导入 CSV”，允许单独选择系数文件并显示其来源和结果集归属。
- 表格原样列出边界编号、名称、`Cl/Cd/Cx/Cy/Cz/Cmx/Cmy/Cmz` 和 `ALL_WALL` 总计；可排序、选择边界和查看文件来源。在边界映射可靠时，可联动查看选中边界的系数。
- 可选择多组 CSV 并列对比；若要画系列线，用户明确指定横轴工况和纵轴系数。结果组、状态信息和参考量缺失时显示未知，不从文件名前缀自动当作已验证数值。
- 如果通过主界面提供相关工况信息，可作为补充显示；CSV 表格本身应能独立打开。

**后台逻辑**

- 解析表头、空白和科学计数法；`ALL` 是文本汇总标识，不能强制转整数；保持原始列和值、文件来源和行类型。
- 识别三面与 `ALL_WALL` 的关系时保留用户可见的来源与规则；不重复把总计与各分项再次相加，不擅自用 `Cl/Cd` 替代三轴系数。
- 明确该表与 CGNS/TEC 的算例和边界匹配策略；多状态汇总、舵效公式和 AI 建模属于扩展分析能力，不能认为单个 CSV 已包含完整训练或状态数据。

### 4.7 多结果集与时间序列

**UI 交互**

- 支持同时保留多个结果集并独立选择/显隐；视需要分别显示网格和系数表。不同算例可以对比，但不自动视作不同时间帧。
- 真正存在时间序列时，用户确认文件顺序与物理时间，使用时间轴首帧、上一帧、播放/暂停、下一帧、末帧和定位；缺失时间标“未知”。

**后台逻辑**

- 保持结果组、帧索引、物理时间和网格/字段版本之间的关系；不同结果组不能互相覆盖。真实时序必须有数据依据或用户显式配置。
- 目前文件名含 `step100`、TEC 中含 `solutiontime`，仍不足以推定物理秒或可播放时序。

### 4.8 截图、动画和主界面产物

**UI 交互**

- “输出”页提供保存截图和动画入口。截图可设置图片尺寸和背景；动画在存在有效时间序列时提供时间范围和尺寸等设置。具体格式与编码仍需确定。
- 截图或动画默认保存在后处理目录，用户可选择位置；主界面的后处理产物列表展示并打开生成的文件。预览不等同于已保存的文件。
- 数据格式转换和特征几何导出暂不纳入当前输出范围。

**后台逻辑**

- 图片与动画使用真实视图和有效帧；输出格式、质量、播放方式与目标资源条件需进一步验证。
- 通过文件交互更新主界面的产物列表，保留文件路径与来源，输出失败时提供原因和重试入口。

### 4.9 版本范围

- **版本**：讨论提出完整版和面向需求的交付版本；各版本保留、隐藏或裁剪的功能清单仍需明确。

## 5. 并行使用、异常与保存要求

- 求解运行期间，应能独立查看**此前已完整生成**的结果，避免后处理窗口阻塞主界面或终止计算。
- 对正在写入、部分生成或被替换的同一个文件，先确认生成端的完成标记、原子写入或快照协议；读到不完整数据时提示并允许重试，不能默认实时读取总是安全。
- 用户同时打开多个结果时，源数据、场景对象、视图设置和错误状态需要明确归属；关闭一个对象不能破坏其他对象。
- 对读写失败、文件不支持、缺少字段/边界、字段不匹配、取消和窗口关闭提供可理解反馈。耗时读取、特征计算和导出异步进行；Widget、VTK 渲染和相机修改留在 GUI 线程。
- 导入、显示和导出默认不改写源文件；如将来提供覆盖源文件的编辑功能，应作为独立操作明确设计。
