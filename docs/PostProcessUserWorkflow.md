# 后处理工作台操作流程与菜单状态

本模块面向已有 Tecplot、CGNS、VTK 网格/结果，独立于工程创建、参数配置和求解运行。结构与非结构网格采用相同的用户操作流程。以下区分目标业务流程与当前 UI 已完成的交互；不表示结果读取、VTK 算法和导出服务已实现。

## 使用顺序

1. **打开工作台**：默认是空会话，中央为 ParaView 风格的暖灰画布，不显示预置云图。无需先运行前处理。
2. **导入已有结果**：目标是从本地选择 Tecplot/CGNS/VTK 文件。读取成功后列出网格类型、Zone、字段、字段分量/关联方式与真实时间。当前导入仅发出请求，读取服务尚未接入。
3. **选择网格和字段**：左侧“数据”选择体网格、物面或字段；画布上方“着色”切换当前对象的标量或矢量模长。字段类型和网格维度共同决定功能是否可用。
4. **创建显示或特征**：创建云图、切面、等值线/面或流线。当前只建立明确标记的草稿，自动切换到“对象”页；双击或“编辑参数…”修改参数。“对象样式…”调整外观草稿。
5. **继续分析**：云图保留源网格维度与字段，创建云图后仍可继续创建切面/等值面；切片作为面对象可进一步提取等值线。生成流线后，可另选标量着色，积分矢量不随着色改变。
6. **查看时间变化并导出**：目标是在真实时间帧间浏览、播放，计算完成后导出选中数据、特征几何或动画。当前时间轴仅供明确标记的界面示例使用，导出按钮保持禁用，草稿不伪装成可导出的计算结果。

当前检查交互时，先打开 **工具 → 界面示例 → 结构网格示例 / 非结构网格示例**。示例只填充窗口内的元信息与草稿，不读文件、不构造 VTK 数据、不执行数值算法。它是开发检查入口，不是实际使用中的必需步骤。

## 菜单变化规则

Ribbon 分类保持稳定；通过动作启用/禁用和提示解释限制，不因生成一幅云图就隐藏整组菜单。

| 当前选择 | 云图/着色 | 切片 | 等值面 | 等值线 | 流线 |
| --- | --- | --- | --- | --- | --- |
| 空会话、分组或时间节点 | 禁用 | 禁用 | 禁用 | 禁用 | 禁用 |
| 只有三维几何、没有字段 | 禁用 | 可创建几何切片 | 禁用 | 禁用 | 禁用 |
| 三维体网格 + 标量 | 可用 | 可用 | 可用 | 先取物面或切片 | 先选有效矢量 |
| 物面/切片 + 标量 | 可用 | 当前入口不对已有面再次切片 | 禁用 | 可用 | 先选有效矢量 |
| 三维体网格 + 矢量 | 模长可着色 | 可用 | 先选标量 | 先选面和标量 | 可用 |
| 物面/切片 + 矢量 | 模长可着色 | 当前入口不对已有面再次切片 | 禁用 | 先选标量 | 表面流线入口可用，表面约束算法待接入 |
| 云图草稿 | 可调整字段与色标 | 按其源网格维度判断 | 按维度和所选标量判断 | 按维度和所选标量判断 | 按维度和所选矢量判断 |
| 流线、等值线等一维对象 | 有标量时可着色 | 禁用 | 禁用 | 禁用 | 禁用 |

切片是几何操作，标量不是必要条件；标量决定切面上能否着色或提取等值特征。“速度大小”是单分量标量，不能替代三分量速度矢量用于流线积分。矢量模长着色也不等于已创建可供等值面算法使用的独立标量数组。

轨迹入口当前按三维矢量与多帧元信息启用，只能建立草稿；会议中的“迹线”究竟是读入已有轨迹还是计算非定常轨迹仍需明确。这次菜单联动没有冻结该算法需求。

当前草稿上的几何后续操作只用于检查交互关系，不代表草稿已经有数值结果。正式接入时，只有上游对象成功计算后，才能提交依赖其几何的计算；失败/计算中对象需显示状态并阻止错误的下游执行。

## 结构与非结构网格的流程

```text
结构网格文件 → 格式读取器 → 保留结构拓扑/块信息 ┐
                                              ├→ 选择 Zone/字段 → 显示/特征 → 输出
非结构网格文件 → 格式读取器 → 保留单元连接关系 ┘
```

两种网格都需要检查几何维度、点/单元字段、缺失值、单位、边界信息和时间对应关系。用户不必先把结构网格转换为非结构网格；某个算法若确有内部转换或点/单元插值要求，由数据/特征模块明确处理并保留来源。本次 UI 不实现这些转换，也不声明支持所有格式版本或单元类型。

求解器输入生成用的网格转换、工况生成与批处理汇总不属于本工作台，因此移除了原首页的“网格转换”和“工况汇总”。后处理自己的分析表输出仍可在分析模块接入。

## 中央视口与背景

“显示 → 视口背景…”提供默认暖灰、经典蓝灰、蓝灰渐变、白色、黑色和自定义颜色；支持十六进制颜色或选色器。“应用”生效，“取消”保留原背景，“恢复默认”先重置对话框，再点击应用。

默认暖灰采用 ParaView `WarmGrayBackground` 的 RGB `(98, 93, 90)`，即 `#625d5a`，数值取自 [ParaView 调色板源码](https://github.com/Kitware/ParaView/blob/master/Remoting/Application/Resources/utilities.xml)。旧版蓝灰与新版暖灰的区别参见 [Kitware 默认背景说明](https://www.kitware.com/new-default-colormap-and-background-in-next-paraview-release/)。这只是参考其画布与背景，不新增 ParaView 运行依赖。

背景设置当前在窗口生命周期内保留，不写入求解结果或系统配置。窗口提供模块内 `backgroundChanged` 信号；正式 VTK Viewer 适配器接入后需在 GUI 线程应用至 renderer。当前已接入的是画布占位绘制，不宣称已改变不存在的 VTK 场景。

## 本次检查范围

按用户要求只进行代码检查，未执行构建、CTest 或原生界面视觉验收。现有 smoke 用例已补充空会话、两种网格的菜单联动、标量/矢量区分、云图后继续操作、流线积分与着色分离，以及背景应用/取消/恢复默认和非法颜色检查，待手动构建运行。

Windows 可按仓库约定运行 `scripts\build-windows.cmd all Debug`。之后使用 `aerosim_gui.exe --postprocess` 打开工作台，从“工具 → 界面示例”检查交互。真实文件读取、特征计算、数值正确性、VTK 渲染与导出仍需各自的后端实现和验收。
