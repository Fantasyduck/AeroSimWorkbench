本轮依据 `VisualizationDataAndRendering.md` 检查 UI 交互，不将读取适配器、VTK 数据和特征计算草稿视为已实现服务。未修改公共契约。

## 导入与数据源

- Plot3D 网格（常见 `.xyz`）包含坐标和网格结构，结果（常见 `.q`）包含流场量。仅查看网格可单独选择网格文件；查看流场需关联匹配的网格和结果文件。扩展名不能证明内容或配对正确。当前 UI 只收集文件，多组配对和格式校验仍待读取适配器实现。
- 导入方式仅显示“追加显示”“替换现有数据”，内部命令值保持不变。替换请求在读取成功前保留现有数据。
- 对象面板的新建对象按“来源文件 / 数据集 → 区域 / 已有对象 → 字段”选择。换文件后重建区域和字段选项；派生对象保留原始来源。Plot3D 的配套文件在正式服务中应组织为同一个逻辑数据源，不能把 `.q` 当作独立几何。
- 字段只取自当前来源上下文，不合并不同文件的字段。当前示例字段是明确标记的 UI 夹具；真实导入文件仍为等待读取，不会虚构可分析字段。字段的节点 / 单元位置与未知单位还需读取服务提供元数据后展示。

## 方向导航

Tecplot 360 的方向辅助是三维坐标轴，另提供球形、滚珠、扭转和轴向旋转工具；不能据此称其方向辅助为可拖动球。[方向轴说明](https://tecplot.azureedge.net/products/360/current/help/users_manual/fieldplt.html)、[旋转操作说明](https://tecplot.azureedge.net/products/360/2023r2/help/Topics/tools_3d_rotate.htm)。

本轮采用轻量 XYZ 导航样式：正负方向、轴色、深度排序、点击标准视角、拖动连续更新朝向；标准视角按钮同步更新方向控件。保留已有视角与拖动请求。当前是 UI 朝向预览，实际模型旋转、相机双向同步及旋转中心应用仍待渲染适配器接入。

## 字段与色标

| 项目 | 含义 |
| --- | --- |
| 字段 | 当前对象使用哪个物理量着色。 |
| 配色方案 | 蓝青黄红适合连续变化；灰度由暗到亮；蓝白红可用于有参考中心的差异展示，但当前没有单独的中点设置，不能承诺白色必定对应零。 |
| 自动：当前对象 / 字段 | 使用当前对象、字段、时间步的实际最小 / 最大值；待真实读取后计算。 |
| 手动：指定上下限 | 固定颜色映射范围，便于跨对象或时间步比较；范围外使用端点颜色，不裁剪数据。最小值必须小于最大值。 |
| 色标显示 | 控制图例显隐；不改变对象显隐。 |
| 数据实际值域 | 数据自身最小 / 最大值，与手动颜色映射范围区分；当前不能显示虚构数值。 |

自动模式禁用手动上下限；手动范围无效时禁止保存或应用。设置仍为草稿，真实颜色映射、图例与时序范围计算待渲染服务实现。
